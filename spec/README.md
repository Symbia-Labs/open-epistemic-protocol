# Open Epistemic Protocol — Specification Directory

This directory contains the formal specifications for the Open Epistemic Protocol (OEP). 
Specifications describe the normative rules, definitions, and structures that govern 
epistemically safe human–machine interaction.

## Files

- **oep-v1.0.md**  
  The canonical specification for OEP version 1.0.  
  Defines claim classes, access/awareness boundaries, and enforcement rules.

- **terminology.md**  
  Shared vocabulary and definitions used across OEP documents.

- **claim-classes.md**  
  Detailed descriptions of the canonical claim classes.

- **enforcement-rules.md**  
  Formal rule definitions for validators and compliant actors.

## Versioning

Specifications follow semantic versioning:
- **MAJOR**: Breaking changes to claim classes or rules  
- **MINOR**: Additions of optional features or extensions  
- **PATCH**: Clarifications, typos, test alignment  

Each stable spec file is named `oep-vX.Y.md` and is immutable once released.

## RFC Relationship

All changes to the specification require an approved RFC.  
See `/rfc` for governance, RFC templates, and proposals.

## Notes

This directory will expand as OEP evolves.  
Initial content includes the v1.0 spec and core definitional files.
